## The SDK

The CR3SCENDO AI SDK will give developers and AI agents programmatic access to the full platform: form companies, manage finances, track compliance, and orchestrate business operations through a single, well-documented API.

**What to expect:**
- Python SDK with async support
- Full API coverage across all platform capabilities
- Simulation mode for safe development and testing
- Multi-tenant architecture (manage multiple organizations)
- Built for AI agent integration from day one

The SDK will be open-sourced when the platform reaches general availability. Star or watch this org to be notified.
